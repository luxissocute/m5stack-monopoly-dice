# Labu 玩具城市 1.0：朋友遠端連線

Windows 成品：`release/Labu-Toy-City-1.0.1-Windows.exe`。遊戲、房間服務及 Cloudflare 加密通道工具均已包含，不需要另外安裝 Node.js、設定路由器或輸入 Wi-Fi 密碼。

## 你當主機，朋友用網址

1. 雙擊 EXE，選「多人遊戲」→「遠端連線」→「建立房間」。單人模式則選「單人遊戲」，每個設定步驟都有上一步。
2. 按「開啟遠端主機」，等待「分享已開啟」。
3. 按「複製主機入口」傳給朋友。這是主機入口，朋友可在裡面自行建立或加入房間，你不必參賽。
4. 若要同一局一起玩：一個人建立房間，複製該房間的邀請連結，再傳給其他人。
5. 朋友用電腦 Chrome／Edge 開啟連結，輸入名字加入。房主按開始，空位由 NPC 補齊。每局 2～4 人。

分享網址內的通行碼是主機入口憑證，請保留完整網址給預定一起玩的朋友。它不包含任何玩家的私人席位憑證。

## 朋友用 App

朋友開同一版 EXE，選「多人遊戲」→「遠端連線」→「加入朋友」，在「朋友的主機網址」貼上完整房間邀請連結。已有房號時會自動讀取，也可另外輸入房號。使用瀏覽器開主機入口時，可直接在此主機建立自己的房間。

每個玩家可自行連接 USB 或藍牙 M5Stack；裝置只控制目前配對的玩家。沒有裝置的玩家仍可用畫面按鈕。

## 只開主機，不參賽

在分享區按「只開主機，縮到背景」。若你已加入房間，程式會先確認離席，再讓 NPC 稍後接手；大廳內的房主離席時，會將開始遊戲權限交給仍在線的朋友。按視窗右上角 X 會詢問「關閉程式／背景執行／取消」。關閉程式會停止主機；背景執行會保留玩家席位並縮到系統匣。「只開主機，縮到背景」則會先處理離席。雙擊系統匣圖示可叫回視窗。主機運作時程式會要求保持喚醒，仍請不要手動休眠、關機或切斷網路。

要結束所有對外連線，按「停止分享」，或從系統匣選「停止分享並結束」。停止分享會立即中斷遠端連線。

## 連線中斷時

短暫網路中斷會自動嘗試接回，最長間隔 15 秒。程式只重新驗證玩家身分，不會補送擲骰、購買等可能已完成的操作。離線超過一段時間，NPC 會暫代；恢復時會在安全的回合邊界交還席位。

這個版本的房間只存在主機程式記憶體中。完全結束主機、重新開機後，舊房間不保留；它不是永久儲存的雲端服務。

## 分享網址的有效期間

此版本使用 Cloudflare Quick Tunnel，無須帳號，但它是暫時性的連線入口：每次重開分享網址可能改變，亦不提供長期可用性保證。通道關閉後舊網址無效；重新分享後請使用新連結，建議重新建立房間。若將來需要固定網址與長期服務，可再改成正式 Cloudflare Tunnel／固定網域。

官方說明：https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/

## 私人主機的範圍

主機不會公開你的原始碼、設定檔或硬碟資料；只提供已建置的遊戲資源與指定的房間連線。遠端入口採完整邀請通行碼、來源檢查、房間席位憑證、訊息大小／頻率與連線數限制。關閉分享後，外部通道與遠端房間連線會停止，本機遊戲仍可操作。

## 重建與驗證

```powershell
npm ci
npm run desktop:pack
```

`desktop/vendor/cloudflared.exe` 與其授權檔需保留；本次下載版本是 2026.10.5，來源為 Cloudflare 官方 GitHub releases。桌面 UI 檢查：`node scripts/test-desktop.cjs`。完整真實外網驗證：`node scripts/test-final-desktop.cjs`，會暫時開啟主機、讓兩個測試瀏覽器加入、擲骰並驗證背景主機，結束後自動停止。執行前先正常關閉舊版 EXE。
