# 1.0 最終版驗證紀錄

日期：2026-10-29（Asia/Taipei）。

## 已通過

- TypeScript 與桌面模式 Vite 建置。
- 完整 Vitest：19 個檔案、148 項測試全部通過。
- 真實 HTTPS／WSS 外網通道：兩個獨立瀏覽器與桌面 App 進入同一房間，三個人類席位收到相同骰點。
- 原始碼模式及已封裝的 `Labu Toy City.exe` 都完成上述外網操作。
- 最終單檔 `Labu-Toy-City-1.0.0-Windows.exe` 已按一般使用方式啟動，通過自動解壓、遊戲視窗、內建資源與房間服務檢查，測試後已關閉。
- 主機視窗縮到背景後，公開遊戲入口仍能使用；「只開主機」會離開玩家席位，連線玩家數正確減少。
- 大廳房主離線會交接權限；明確離席會釋放大廳名額，朋友仍能填滿全部人類席位。
- 中斷 WebSocket 後自動重新驗證原席位，原擲骰操作不會再送一次。
- 沒有通行碼或通行碼錯誤的外網 HTTP 請求被拒絕；停止分享會中斷遠端 WebSocket。
- 外網瀏覽器能透過安全邀請 Cookie 載入私有遊戲資源；邀請連結不含玩家私人席位憑證。
- 通道工具 Cloudflared 2026.10.5 的檔案雜湊符合 Cloudflare 官方發行資產 SHA256。

外網測試使用同一台實體電腦上的獨立瀏覽器／App 客戶端，實際繞經公開的 Cloudflare HTTPS／WSS 入口；並非只用 localhost 模擬。尚未在朋友的另一台實體電腦、不同 ISP 上另外手動驗收。

## 已知範圍

- Quick Tunnel 為暫時網址，不提供長期可用性保證；每次重開分享可能換網址。程式會先檢查外網遊戲頁面可用，才顯示已開啟。
- 主機程序結束或電腦關機後，記憶體中的房間不會保留；不是永久雲端存檔。
- 本次遠端更新未改動 C Plus 韌體。USB／BLE 共用的事件與回合限制沿用原版本；硬體無線實際續航仍未量測。
- 遊戲既有大型 Three.js 分包警告及舊介面設計檢測提示仍存在，不影響本次建置與遊玩測試。

測試開啟的分享通道均已停止。成品預設不對外分享，需使用者按「開啟遠端主機」才啟動入口。
