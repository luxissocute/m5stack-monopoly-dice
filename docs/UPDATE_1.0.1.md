# 1.0.1 更新驗證（2026-10-30）

- 遊玩流程：先選單人／多人，多人再選本機同桌／遠端連線；遠端再選建立／加入。設定階段有實體外觀的上一步按鈕，回退保留輸入。
- 房間邀請優先顯示；主機入口標明供朋友自行開房。App 使用經來源檢查的 Electron 系統剪貼簿，瀏覽器有權限拒絕時的備援複製與手動提示。
- X 顯示關閉程式／背景執行／取消。實測取消保留視窗、背景保留服務、關閉停止服務。「只開主機」仍為獨立離席功能。
- TypeScript 通過；20 個測試檔、152 個測試通過。修正既有伺服器測試的計時競態：在移動開始前驗證禁止客戶端 step，避免與伺服器自動推進版本競爭。
- 真實 Cloudflare 外網多人測試通過：兩個瀏覽器與 App 同房、骰點同步、背景服務及離席。
- 最終打包版實測：兩個複製按鈕寫入 Windows 剪貼簿的內容與畫面完整網址相同（包含房號與通行碼）；瀏覽器 API 刻意拒絕仍成功；X 的三個選項均驗證。測試後還原原剪貼簿。
- 單檔 EXE 解壓啟動、視窗、內建資源與房間服務測試通過。
